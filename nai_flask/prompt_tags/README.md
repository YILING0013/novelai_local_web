# 本地提示词词库

同步主项目 `nai_flask/data/prompt_tags` 的 23 个 CSV，内容保持原样。原始来源为 Gallery V1.0 正式版的 `程序/scripts/搜索辅助数据`（2026-09-30 快照）；源数据没有附带独立许可证，本文件不额外声明授权范围。

CSV 为 UTF-8，列为 `单词,分组,引用量,历史版本,翻译`，合计 1,306,840 字节，规范化去重后 31,076 个标签。词库是随代码分发的只读资源，不进入用户数据目录，不修改原始文件。

英文联想继续使用用户当前账号访问 NovelAI 官方端点，中文直接查本地词库；完整标签翻译也留在本机，不引入第三方联想服务。官方联想不可用时，响应的 `upstream_status` 为 `unavailable`，本地结果仍可使用。只记录错误类型，不记录搜索词或 Token。

更新时连同后端代码完整复制本目录，然后重启本地服务。词库缺失或格式错误会在启动时明确报错。
