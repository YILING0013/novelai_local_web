# 漫画提示词

在 **AI制作** 中可以提供一句剧情，也可以粘贴已有的 NovelAI 提示词。要约束画面，优先写清人物外观、关键动作、画风和对白语言。想保留指定台词时，把台词直接写进输入，编排后核对预览。要求无字漫画时，在输入中明确说明。

编排依次扩写故事、提取画风和人物，再设计分镜并准备绘图提示。修改预览中的某次人物出场时，直接编辑该出场的提示词和位置。修改台词后已有原图的区域可用 **仅重建文字**。

配置和操作见 [本地 AI 漫画制作](ai-comic-local.md)。维护提示词时以运行代码为准。 [原生版提示词](../src-tauri/resources/comic-prompts.json) · [源码 Web 版编排](../nai_flask/api_utils/comic_planner.py)
