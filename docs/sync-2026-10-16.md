## 更新前检查与更新顺序

新增前端依赖 `ag-psd`（声明 `^30.1.0`，锁定 `30.2.0`）和 `fflate`（`0.8.3`），锁文件同步提交。其余已锁定依赖版本保持不变。无新增后端依赖、环境变量、后端持久化目录、权限要求、数据迁移或端口变更。

1. 关闭正在运行的本地服务，保留更新前源代码、锁文件和 `next_nai_web/out` 的备份；浏览器漫画项目可通过“导出项目”单独备份。
2. 在本地版 `next_nai_web` 目录执行 `npm install`，随后执行 `npm run build`。依赖安装、构建或发布扫描失败时停止更新，不启动不完整的静态产物。
3. 在本地版仓库根目录执行 `nai_flask/.venv/Scripts/python.exe scripts/verify_release.py`，预期输出“发布扫描通过”。
4. 使用原有 `start.bat` 或 `start-lan.bat` 启动并刷新页面。无需额外 Node 服务或后端迁移；构建产物仍为 `next_nai_web/out`，由原本地服务读取。
5. 验证普通生成参数、漫画切割及旋转、图库发送到图像处理、项目下载与刷新恢复，以及手机布局。登录和真实生成仍使用用户自己的 NovelAI 账户。

本轮没有发布测试站或稳定站。回退时恢复旧源码、对应锁文件并重新安装及构建，或恢复完整旧静态产物，再使用原启动入口启动。旧磁盘图库和笔记格式未变；旧界面无法打开新增图像处理工作区，但不要删除其浏览器数据。更新后编辑过的漫画应保留新版导出备份，旧版不能完整呈现新增旋转效果。
