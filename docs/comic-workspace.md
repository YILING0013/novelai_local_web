# 漫画制作

在绘画工作区选择 **漫画**。可手工搭建画框、为各格生成图片，也可以让 AI 从剧情编排整页。 [AI 漫画制作](ai-comic-local.md)

## 排版和编辑

- 选择竖版、横版、双列或双行，应用分镜模板，也可自定义画布尺寸。修改已有页面的尺寸时，画框和元素保留原位置，超出画布部分暂不显示。
- 用**切割**选择同一画框边缘的两个点，用**拉框**画出新画框。选中画框后，拖动手柄可调整位置、边缘、顶点或角度。
- 从文件或画廊载入画框图片，用**调整构图**设置图片位置与缩放。可以添加画笔笔迹、气泡、文本和贴纸，并在图层面板管理显示、锁定与顺序。
- 手机端从工具栏打开绘图工具、参数与页面列表。

## 分镜生成

1. 切换到 **手动编排**，选择画框，编辑提示词、角色与生成参数。点击**使用推荐分辨率**可按画框比例设置尺寸。
2. 点击 **暂存任务** 保存该画框的参数。在底部操作栏生成当前画框，或使用 **依次生成所有分镜**。
3. 生成结果会回到提交时的画框。原画框已删除时，可到本地画廊或本次生成记录找回图像。

## 保存和搬迁

- **保存漫画页**将当前页放入页面库。未保存的编辑可从同一工作区的草稿继续。
- **导出项目**保留页面、草稿、图层和素材。换设备、浏览器或访问地址前先导出，再在目标工作区**导入项目**。
- **导出 ZIP**按已保存的页序输出 PNG。需要在图像编辑器继续处理时，可从[图像处理](image-processing.md)导入漫画项目。

## 桌面快捷键

| 按键 | 操作 |
| --- | --- |
| V / C / U / Shift+U | 选择 / 切割 / 拉框 / 叠加画框 |
| B / E / H / Z | 画笔 / 橡皮 / 抓手 / 缩放 |
| Shift+C | 调整构图 |
| Space 或鼠标中键 | 临时平移 |
| 滚轮 / Ctrl+0 | 缩放 / 适应画布 |
| Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z | 撤销 / 重做 / 重做 |
| Ctrl+S / Ctrl+Shift+S | 保存漫画页 / 保存模板 |
| Ctrl+N / Ctrl+O / Ctrl+J | 新建页 / 上传图像 / 复制选中内容 |
| Delete / [ / ] | 删除选中内容 / 减小笔刷 / 增大笔刷 |
