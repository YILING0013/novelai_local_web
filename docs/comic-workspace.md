# 漫画制作

从绘画区域左侧、Inpaint 下方的“漫画制作”进入。普通绘图和漫画画框分别保留提示词、角色、图生图、Vibe 与参考图编辑状态。漫画生成继续使用本地后端和用户配置的 NovelAI 账号；费用按模型与参数计算。

## 页面与内容

- 支持竖版、横版、双列竖版和双行横版，提供 28 种分镜模板。跨页中的两个版块可分别应用模板，也可保存自定义模板。
- 选择画框后，拖动外置移动端点移动整框，圆点调整顶点，方点调整边。画框内部用于选择，不会拖动整个画框。
- “切割”依次选择同一画框边缘的两点，可斜切；“拉框”拖出矩形。“叠加画框”可跨过普通画框，透明图片保留透明区域。
- 画笔和橡皮作为独立笔画保存。橡皮把划过位置涂白，不改变画框几何或生成任务。
- 可上传图片、从本次生成或本地生成画廊选图，再打开“调整构图”拖动、缩放图片。本地画廊分页加载，并读取所选原图。
- 对话框有 12 种预设，支持上传 PNG、JPEG、WebP 或 SVG；贴纸使用同一编辑能力。可调整轮廓、透明遮罩、旋转、倾斜、大小、镜像、羽化及文字。
- 文本可在画布拖出区域，支持横排、竖排以及上传 TTF、OTF、WOFF、WOFF2 字体。
- 右下角打开图层面板。默认按普通画框、叠加框、对话内容排列，可增建、改名、隐藏、锁定、调整顺序或向下合并。内容前后移动只改变其所在图层内的次序。

## 画框生成参数

选择画框，点击“编辑生成参数”。“图像大小”旁的“使用推荐分辨率”按当前画框的外接矩形比例匹配允许尺寸；同样接近时选择像素更多的尺寸。普通模式和用户已启用的大图模式分别遵守现有的尺寸限制，推荐不会自行开启大图模式。

只有点击按钮才会更改宽高。进入参数区、重开、切框或手动修改参数不会自动执行推荐。每个画框的参数独立保存，返回普通绘图时恢复之前的普通绘图内容。

生成请求固定发起时的画框和参数。期间切换画框或页面，结果仍回到原画框；原画框已删除时，结果仍保留在本地画廊和本次生成列表。连续生成沿用本地版最多 8 张、相邻请求间隔 15 秒的规则，每张使用新 Seed，画框显示最后一张。取消阻止后续请求，保留已经返回的图像。

后端先尝试保存原图到输出目录，再返回图像。磁盘保存失败时，漫画仍接收已生成的结果并明确警告，停止后续连续生成；请手动下载原图或导出项目，再检查目录权限及磁盘空间。

## 保存与搬迁

- 页面编辑自动暂存为当前草稿。“保存漫画页”把页面加入页面库，可重新打开、排序或删除。
- “导出 ZIP”按已保存的页面顺序输出 `001.png`、`002.png` 等图片；它不包含继续编辑所需的结构。
- “导出项目”打包全部页面及当前草稿，包含图像、图层、笔画、对话框、文本、字体、生成任务和自定义模板。当前未保存修改也会进入项目包。
- “导入项目”恢复成新的页面与模板副本，不覆盖已有页面。项目包沿用版本 1 格式；任务执行仅支持本地版提供的 NovelAI 模型。
- 漫画资料保存在当前浏览器的 IndexedDB，数据库为 `novelai-comic-workspace`。它不在后端数据目录里，也不会自动随图片目录备份。
- 更换浏览器、电脑、端口，或由 `localhost` 改用局域网 IP，会进入另一个浏览器存储空间。搬迁前导出项目，随后在目标地址导入。

漫画工作区本身不新增后端配置、目录权限或数据迁移。2026-10-16 的图像处理集成另有前端依赖，更新步骤见 [同步清单](sync-2026-10-16.md)。

## 快捷键与手机操作

| 快捷键 | 操作 |
| --- | --- |
| V / C / U / Shift+U | 选择 / 切割 / 拉框 / 叠加画框 |
| B / E / H / Z | 画笔 / 橡皮 / 抓手 / 缩放 |
| Shift+C | 调整分镜构图 |
| Space 或鼠标中键 | 临时平移画布 |
| 鼠标滚轮 / Ctrl+0 | 缩放画布 / 适应画布 |
| Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z | 撤销 / 重做 / 重做 |
| Ctrl+S / Ctrl+Shift+S | 保存漫画页 / 保存模板 |
| Ctrl+N / Ctrl+O / Ctrl+J | 新建页 / 上传图像 / 复制选中内容 |
| Delete / [ / ] | 删除选中内容 / 减小画笔 / 增大画笔 |

输入文字、打开弹窗或切到其他工作区时，漫画快捷键不会抢占输入。工具提示显示名称和快捷键。手机端按钮使用图标，左下角显示最近操作名称，右上角菜单打开页面库；画布工具与元素编辑器支持触摸操作。

## 2026-10-16 交互更新

- 切割线靠近画框边界时吸附并高亮；支持依次点击两条边，或从画框外拖过后松手切割。Esc 取消，撤销恢复整次切割。
- 画框移动与旋转时图像构图跟随变换；导出图片和项目也保留旋转。
- 元素增加四角、四边缩放和独立旋转手柄。Shift 保持比例或按 15 度旋转，Alt 暂停移动吸附。
- 图像处理可读取当前草稿、保存页或漫画项目 ZIP，按页生成独立文档，保留可编辑图层。原漫画库保持不变。
