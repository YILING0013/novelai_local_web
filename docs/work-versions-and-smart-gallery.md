# 作品版本与智能图库

## 建立和继续作品

1. 在绘画工作台点击 **新建作品**。首张生成图片成为 V1，也可以从画廊把已有图片加入作品。
2. 点击 **作品蓝图** 查看各版本与分支。可对比图片、正负提示词、角色、权重和生成参数，也可拖动节点、框选成组、折叠分支或给连线加备注。
3. 选择一个节点后，**应用所有参数**会将该版本的设置填入编辑区。想让下一张生成图成为该节点的子版本时，点击 **从此节点继续**。
4. 有 V1 后，可用 **保存提示词版本** 记录草稿，无需生图。**恢复为新版本**会把旧版本的图片和参数添加到作品末尾。**退出作品**后继续普通生成，之后可用 **打开作品** 找回历史。

节点能恢复保存时的 Seed、角色、参考、图生图及重绘遮罩。较早的节点可能缺少当时未保存的素材。生成图已保存但版本记录失败时，可从画廊把该图加入作品。

## 搜索、筛选和收藏

- **智能筛选**可组合标题或提示词搜索、模型、画幅、标签与分组。
- 在图片详情点击 **找相似提示词**，可按提示词内容找相关图片。
- 将一组条件保存为**动态收藏**后，符合条件的新图会自动显示。删除收藏只清除筛选条件。

## 备份和删除

关闭应用或服务后，备份完整工作区和自定义图片目录。源码 Web 版需要同时备份 `image-library.db` 和 `version-assets/`。各平台的资料位置与导出方式见 [数据与备份](../README.md#数据与备份)。

作品历史保存独立的图片快照。删除作品会永久删除其版本及无其他作品引用的快照，画廊中的原图仍保留。
