# 本地 AI 漫画制作

在漫画工作区选择 **AI制作**，可以把一句剧情或一组 NovelAI 提示词编排成漫画。编排可使用 NovelAI 或自定义文字模型，生图使用登录的 NovelAI 账户。文字识别、去字和对白重建由运行工作区的设备使用 CPU 完成，首次生成时会准备本地文字模型。

## 制作漫画页

1. 新建漫画页，选择竖版、横版、双列或双行。可以先排好参考分镜，也可以直接从空白布局开始。双列和双行会按区依次生成。
2. 打开 **AI制作**，填写剧情或提示词。可选填人物、画风及对白语言。
3. 点击 **开始编排**。预览分镜、角色和对白，拖动编号圆点调整角色位置。点击圆点可编辑对应角色的提示词。参考框用于引导编排，生成图片会替换对应区域的排版。
4. 点击 **确认预览并生成**。生成结果回填画布，可以继续修改对白的文字、位置、大小和方向。原图保存在 **AI 生成原图** 图层，供核对。
5. 点击 **保存漫画页**。迁移或备份时用 **导出项目** 保留可编辑内容，交付成图时用 **导出 ZIP** 按页输出 PNG。

想逐格控制时，切到 **手动编排**，选中画框并设置参数，可用 **暂存任务** 保存该格配置。底部可单独生成当前分镜，或选择 **依次生成所有分镜**。更多排版、工具和快捷键见 [漫画制作](comic-workspace.md)。

输入剧情与台词的写法见 [漫画提示词](comic-prompts-current.zh-CN.md)。

## 核对文字与重试

- 绿色框表示已建立可编辑文字，橙色框表示需核对的原图文字。选中识别区域，可保留原文、仅擦除、匹配计划台词或输入自定义文本，再点击 **应用文字修改**。漏检的对白可以用画布的文字工具补上。
- 有原图时用 **仅重建文字** 重做文字层，无需再请求生图。需要更换底图时用 **重新生成本区（消耗额度）**。
- 若结果显示 **待应用**，核对后再选择 **替换本区当前内容（可撤销）**。中途停止后，已发出的生图请求返回时仍会保存图片，重试前可先查看画廊。

## 使用自己的 AI API

1. 打开 **AI制作 → 模型设置**，添加服务商配置。
2. 选择协议，填写服务商提供的 **Base URL**、**API Key** 和**默认模型**。Base URL 填接口前缀，例如 OpenAI 兼容接口通常填到 `/v1`。支持 OpenAI 兼容、Claude、Gemini 和 DeepSeek 旧版协议。
3. 将该配置设为**默认 Provider**，点击 **保存**，再点击 **测试连接**。测试会调用分镜模型，使用服务商额度。
4. 需要分开指定故事、人物提取或分镜模型时，展开 **分步模型与生成参数**。服务商不支持 JSON Schema 时，从**结构化输出**选择该接口支持的格式。

切回内置 **NovelAI** 配置即可使用当前 NovelAI 账户编排。勾选 **记住密钥** 会在本机保留 API Key，其中源码 Web 版以明文写入数据目录。要移除已保存的密钥，点击 **清除密钥** 并保存。
