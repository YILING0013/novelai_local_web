# 图像处理

绘画工作区第四个入口为“图像处理”。首次进入时加载编辑器，默认显示透明空白画布。编辑代码来自主项目集成的 Compositor，MIT 许可保留在 `next_nai_web/src/components/ai-painting/ImageProcessing/compositor/LICENSE`。

## 图片和漫画导入

- 可直接导入图片、PSD 或编辑器项目文件；图片成为独立图层，首张图片决定空白文档尺寸。
- “从画廊导入”包含本次生成、本地图库和参考图库。本地图库通过现有 Flask 会话接口分页查询，每页 60 张，可搜索和继续加载；“选择已加载图片”只选择当前列表。
- 图库详情及生成结果工具栏中的“发送到图像处理”打开对应原图。既有提示词、生成参数、磁盘原图及图库元数据不变。
- “导入漫画项目”可选当前漫画草稿、保存页，或读取漫画项目 ZIP。每页成为一个文档；漫画图层成为分组，分镜图片、边框、笔迹和元素保留独立图层。裁剪转成蒙版，普通文字仍可编辑，倾斜元素按对象栅格化。
- 图像处理、漫画、局部重绘和普通生成之间可切换；离开当前工作区后，其快捷键不会继续操作隐藏画布。

## 保存和备份

图像处理项目自动保存在当前地址、当前浏览器的 IndexedDB `novelai-image-processing` 中。独立保存的笔刷、配色和面板预设也保存在浏览器；这些内容不属于后端磁盘图库备份。

“保存项目”下载 `.compweb`，可再次打开继续编辑；导出支持 PNG、JPEG、WebP 和 PDF。导出的文件通过浏览器下载，不自动写回原图或图库。若需要加入参考图库，可再上传导出的图片。

更换浏览器、地址或端口前先下载项目。漫画与图像处理使用独立存储，导入漫画不会覆盖原漫画库；回退旧版本时不要清空浏览器存储。

## 本地兼容和限制

- 沿用现有本地登录、会话和图库读取权限；没有新增后端接口或远程图像服务。
- 图层、文档和请求 ID 使用本地版既有实现，支持局域网 HTTP。
- 主入口、图库导入和错误提示支持中英文；迁入编辑器的部分高级菜单及面板名称仍保留中文。
- 编辑在浏览器内执行，大尺寸文档与大量图层受设备内存限制。PSD 仅支持 [ag-psd](https://github.com/Agamnentzar/ag-psd) 能读取的内容，不保证所有 Photoshop 效果无损往返。
