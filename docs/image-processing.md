# 图像处理

从工作区导航打开 **图像处理**，可以用图层、画笔、选区、文字和滤镜编辑图片。手机端可从工具栏打开绘图工具。

## 导入素材

- **文件**。支持图片、PSD 和 `.compweb` 项目。导入的图片成为独立图层，第一张图片会设置空白文档的尺寸。部分 Photoshop 专有图层效果可能无法完整导入。
- **画廊**。用 **从画廊导入** 选择本次生成、本地图库或参考图库中的图片。也可以在图片详情或生成结果工具栏中点击 **发送到图像处理**。
- **漫画**。用 **导入漫画项目** 选择漫画草稿、保存页或项目 ZIP。每页会成为一个独立文档，保留图层分组，普通文字可继续编辑。

## 保存和导出

**保存项目**导出可重新编辑的 `.compweb` 文件。**导出**可保存 PNG、JPEG、WebP 或 PDF 副本。自动暂存依赖设备和当前应用或浏览器的存储，换设备、浏览器或访问地址前请先导出项目。
